DAG
Directed Acyclic Graph
Safe · Hierarchical · Shared Nodes
A DAG allows files and subdirectories to be shared across multiple parent directories without duplicating data. Because it strictly prevents cycles (A -> B -> A), standard recursive traversal algorithms can safely navigate the structure without infinite loops.
